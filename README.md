# React Learning Projects ⚛️

This repository is a collection of small projects I built while learning React.

Instead of just watching tutorials and reading concepts, I wanted to understand React by actually building things. These projects are part of that process.

## What I've Built So Far

### 🎨 Background Color Changer

A small React project where I can change the background color by clicking different buttons.

**What I practiced:**
- `useState`
- Event handling
- Dynamic styling
- Tailwind CSS

**Project folder:** `bgchange_color`

---

### 👁️ Real-Time Object Detection

This project uses the webcam to detect objects in real time directly in the browser.

It uses **TensorFlow.js and COCO-SSD** to detect objects and display their names with bounding boxes.

**What I practiced:**
- React Hooks
- Webcam integration
- TensorFlow.js
- COCO-SSD
- HTML Canvas
- Real-time detection

**Project folder:** `objectdetected`

---

### 🔐 Password Generator

A simple password generator where I can choose the password length and decide whether numbers and special characters should be included.

It also has a copy button to quickly copy the generated password.

**What I practiced:**
- `useState`
- `useEffect`
- `useCallback`
- `useRef`
- Clipboard API
- Tailwind CSS

**Project folder:** `passwordgenerator`
